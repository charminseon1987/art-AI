
# Art AI

This project contains the backend API and frontend for the Art AI application.

## Getting Started

### Backend

1.  Install dependencies: `uv sync`
2.  Run the API server: `uv run python api_server.py` or `./start_api.sh`

### Frontend

1.  Navigate to `frontend`: `cd frontend`
2.  Install dependencies: `npm install`
3.  Run the development server: `npm run dev`
