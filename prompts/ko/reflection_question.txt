다음 그림 분석 결과를 바탕으로 사용자가 자기 탐색에 활용할 수 있는 질문을 생성하세요.

**질문 생성 원칙**:
1. 그림의 구체적인 요소에 대한 탐색 질문 (색상, 형태, 구성 등)
2. 감정적 표현에 대한 탐색 질문
3. 시각적 특징에 대한 탐색 질문
4. 그림 제작 경험에 대한 탐색 질문

**질문 특성**:
- 개방적이고 탐색적인 질문
- 사용자가 자신의 그림을 더 깊이 이해하고 탐색할 수 있도록 구성
- 각 질문에 대해 그림의 시각적 요소와 감정적 표현을 스스로 생각하고 표현할 수 있어야 함
- 각 카테고리별로 2-3개의 질문 생성

**출력 형식**: JSON 형식으로 구조화된 질문 목록을 제공하세요. 다음 필드를 포함해야 합니다:
- questions: 질문 배열
- categories: 질문 카테고리 배열 (예: ["색상/형태", "감정", "상징", "경험"])
- purpose: 질문 생성의 목적 설명

⚠️ 진단이나 치료 목적의 질문이 아닌, 교육적 자기 탐색 질문만 생성하세요.
